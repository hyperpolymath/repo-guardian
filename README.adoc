== What this is intended to be

`repo-guardian` is the placeholder for repository-guard tooling in the
hyperpolymath estate. Two components are scaffolded:

`mcp-repo-guardian`:: intended MCP server surface.
`repo-guardian-fs`:: intended filesystem-side component.

Neither directory currently holds an implementation.

== Why the banner

Estate policy prefers an honest status banner over a README that describes
unbuilt features. A README promising behaviour that does not exist is worse
than an empty repository: it makes hollow scaffolding read as finished work.
If you are looking for working guard tooling, this is not it yet.
